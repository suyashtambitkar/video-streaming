# Streamify – Video Streaming Application

Streamify is a full-stack video streaming web application similar to YouTube, where users can create accounts, manage profiles, upload videos, save videos, and watch content uploaded by other users.

---

## 🚀 Features

- User authentication (Register & Login)
- User profile management
- Upload videos with thumbnails
- Watch videos uploaded by other users
- Save videos for later viewing
- Secure routes using JWT authentication
- Responsive UI for all screen sizes

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

### Cloud Services
- Cloudinary (video & thumbnail storage)
